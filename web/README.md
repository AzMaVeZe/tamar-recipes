# המתכונים של תמר — Wix Headless project

This folder is the source of the live site at
**https://t-c-inline-9f66df29-zitnitskicpa.wix-site-host.com/**
(Wix Headless instant site `dd523b32-cb95-49f6-a43b-a232e79e4e58`).

The site was originally scaffolded by the "Send to Wix" flow from a claude.ai
Design project. `wix.config.json` was generated by that flow and links this
folder to the OAuth client Wix created for us.

## Structure

- `index.html` — homepage. Header + hero + filter chips + 24 recipe cards + footer.
  Each card is an `<a href="/recipes/recipe-NN.html">`, so the links work.
- `recipes/recipe-01.html` … `recipe-24.html` — one stub page per recipe
  ("בקרוב — [name]"). Replace with real content as it's authored.
- `recipes.html`, `categories.html`, `about.html`, `add-recipe.html` —
  header nav destinations (also stubs for now).
- `wix.config.json` — Wix project metadata (`projectType: Site`, `appId`,
  `siteId`, `outputDirectory: ./dist`). **Do not commit changes to `siteId`
  or `appId`.**

## Deploy

Deploys are automated via GitHub Actions
(`.github/workflows/wix-deploy.yml`). Every push that touches `web/**`
publishes to the live URL above.

### One-time setup (per repo)

1. Create a Wix API key in the Wix account settings —
   https://manage.wix.com/account/api-keys → **Generate API Key**.
   Copy the value once (it's shown only once).
2. In GitHub, go to
   **Settings → Secrets and variables → Actions → New repository secret**,
   name it `WIX_API_KEY`, paste the key.
3. Push any change under `web/` (or manually re-run the workflow from
   the Actions tab). The job installs `@wix/cli`, logs in with the key,
   and runs `wix release`.

### Manual redeploy

**Actions** tab → *Deploy web/ to Wix Headless* → **Run workflow**.

### Rotating the key

Revoke the old key at the Wix API Keys page and update the GitHub
secret; the next push uses the new one automatically.

### Deploying from a laptop instead

If you'd rather run the CLI locally instead of through CI:

```bash
npm install -g @wix/cli   # or use npx below
cd web
npx -y @wix/cli login     # opens a browser; or --api-key "..."
npx -y @wix/cli release
```

## Why this exists (context on the migration)

We first tried the `import-claude-design-from-url` flow, which normalizes
HTML into Wix Editor components — it kept dropping elements (filter chips,
scattered background scans) and always produced anchor-less pages. Wix
Headless deploys the HTML **as-is**, so we get pixel-fidelity and real
`<a href>` links. See `PR #1` and `scratchpad/PLAN.md` for the full history.
